Política de privacidad

Gestor de Canales · última actualización: 7 de noviembre de 2026

Gestor de Canales es una herramienta privada que su propietario ejecuta en su propio ordenador para gestionar sus propios canales de YouTube. Esta página explica qué datos usa y cómo.

Datos a los que accede

Con el permiso que el titular de cada canal concede en la página de Google, la aplicación usa los servicios de API de YouTube para:

  • subir y programar vídeos y miniaturas, y editar sus títulos, descripciones, etiquetas y listas;
  • leer las estadísticas e ingresos del canal (YouTube Analytics);
  • leer y responder los comentarios del canal.

Dónde se guardan

Los permisos (tokens de acceso) y los datos obtenidos se guardan únicamente en el ordenador del propietario. No se envían a ningún servidor propio ni de terceros, no se venden, no se comparten y no se usan con fines publicitarios. La aplicación solo se comunica con los servidores de Google.

Uso limitado

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Servicios de YouTube y Google

Esta aplicación usa los servicios de API de YouTube. Al usarla se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el acceso

El titular puede retirar el permiso en cualquier momento desde la página de seguridad de su cuenta de Google. Al hacerlo, la aplicación deja de tener acceso y el propietario puede borrar los datos locales de ese canal.

Contacto

Para cualquier consulta, escribe al correo de contacto del desarrollador que aparece en la pantalla de permisos de Google.
